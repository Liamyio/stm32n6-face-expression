# 最终模型文件 — 说明

本目录在本地工程中存放两个最终部署模型与 PC 端演示脚本。公开仓库中仅保留 `cam_demo.py` 与本说明，ONNX 模型文件未随仓库提供，原因见下表。

## 文件清单（本地工程口径）

| 文件 | 大小 | 公开情况 | 说明 |
|---|---|---|---|
| `best_model_opset17.onnx` | 44.7 MB | 未包含 | 表情识别 ResNet18 原始 FP32 模型（opset 17） |
| `best_model_int8(1).onnx` | 941 KB | 未包含 | 表情模型静态 QDQ INT8 量化版，实际部署所用 |
| `rfb320_int8_qdq.onnx` | 413 KB | 未包含 | 人脸检测 RFB-320 静态 QDQ INT8 量化版，实际部署所用 |
| `cam_demo.py` | — | 已包含 | PC 端双模型验证 demo（Haar 检测 + 表情 ONNX 推理） |

- 表情模型为团队自训成果，权重不公开；其部署权重数据、生成代码同样未包含。量化前后的 epoch 分布与内存统计见 `03_表情模型INT8生成产物/` 中的生成报告。
- 人脸模型为开源 RFB-320 的量化版；其部署形态（权重数据 `face_net-data.hex` 与 ST Edge AI 生成代码）已包含在 `01_双模型主工程/` 中，可直接追溯。

## 表情模型接口规格

| 项目 | 值 |
|---|---|
| 架构 | ResNet18（从头训练，80 epoch，自建 7 类数据集，FP32 测试精度 93.68%） |
| 输入 | `[1, 3, 224, 224]` NCHW，RGB，归一化 `x / 127.5 - 1.0` |
| 输出 | `[1, 7]` 原始 logits，端侧加 softmax |
| 类别 | 0 Anger / 1 Disgust / 2 Fear / 3 Happiness / 4 Neutral / 5 Sadness / 6 Surprise |

## 人脸模型接口规格

| 项目 | 值 |
|---|---|
| 架构 | RFB-320（Ultra-Light 开源人脸检测家族） |
| 输入 | 320 × 240（板端管线口径） |
| 输出 | 人脸框 + 置信度，板端做 NMS 与坐标映射后裁剪人脸区域 |

PC 端验证流程与结果见 `08_PC模型验证工具/`；板端完整管线见根目录 README。
